# テイスティング記録（logs）

各ファイルは **1回飲んだときの canonical 記録** です。

## ファイル名の規則

```
logs/YYYY/YYYY-MM-DD_生産者_ワイン名.md
```

- `YYYY`: 飲んだ年（フォルダ）
- 日付・生産者・ワイン名はラベルや記憶に基づく。不明な部分は省略や「不明」でよいが、**推測で埋めない**

## はじめ方

1. [`templates/wine-log.md`](../templates/wine-log.md) をコピー
2. 上記の規則で保存
3. 該当する [地域インデックス](../indexes/README.md) と [品種インデックス](../indexes/README.md) に **相対リンクだけ** を追加

（まだ記録ファイルはありません。）
